Verify the SHA-256 checksum

Open PowerShell in the folder that contains the installer and run the command below, replacing the file name with the one shown on the download page.

Get-FileHash .\{{ latest.installer_name if latest else 'SHADOW-MODEL-setup.exe' }} -Algorithm SHA256

Compare the returned hash with the checksum published on the Download page. If they differ, delete the file and do not run it.
